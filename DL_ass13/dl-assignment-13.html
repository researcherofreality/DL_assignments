13.1 Predicting the weather (7 points)¶

Most people don't like to be oustide in the rain. Fortunately, we nowadays have radar sensors, that can show the amount of precipitation over a wide area in real time. Weather services like buienradar use this data to forecast when it will rain. But the models they use are often quite simple: just move the rainclouds according to the current wind patterns.

In this assignment you will investigate whether you you can do better with deep learning.

More concretely: The task that we have in mind is to predict the amount of rain up to 3 hours in advance, for the entire country of the Netherlands. The input will be radar images of the amount of rain currently falling. For training, there is historical radar data going back several years. You may assume that the data has been gathered with a sample rate of 5 minutes, and at a resolution of 1500m per pixel. See the KNMI website for more information.

(a) Are there risks of unfair biases in this task? Explain your answer. (1 point)

As always, some biases exist.

The main bias would be that it is based on historical data, and the weather is a stochastic system, portraying chaotic behaviour which is not found in previous historical data.

Moreover, the data collection system is also somewhat biased, given that some parts of the country are more densely populated than others, which would require more accurate measurement for accuracy per person than sparsely populated parts.

(b) Suppose we want to use a deep neural network for this task. How would the input data be represented? (1 point)

For now, consider using only the current radar data as input.

So the main input is the current radar data. This would be a snapshot of the rainfall in a set unit - i.e. rainfall in mm - , at all locations. First of all, this snapshot would probably be processed to normalize over all snapshots, and smooth between the recording locations. We can resize the rainfall per locations to the physical locations in the Netherlands as well.

Consequently, we want to add in both the temporal and spatial features, which account for the dynamics. This can be done with some metadata such as position coordinates and timestamps.

(c) What are the targets for prediction? How are they represented? (1 point)

The target of prediction was the amount of rain up to 3 hours in advance for the entire country of the Netherlands. This would be in the same format as the input data, i.e. the amount of rainfall in mm per location in a grid-like structure output, but it would be accumulated over the 3 hours.

(d) If we want to make a prediction for the entire country of the Netherlands, how large should the input be to contain all the relevant information? (1 point)

13.2 Weather prediction models (4 points)¶

Consider a model that uses only the current radar data and terrain as input, to predict rain 3 hours in the future.

(a) What kind of model would you use for this task? (1 point)

Since we are neglecting the temporal component - which we would represent with a RNN/LSTM - we only look at the spatial component of the input, which would best be modelled using a CNN.

(b) How would the performance of a model that takes only a single radar image as input compare against the simple baseline model that moves the radar image in the wind direction? (1 point)

It would most probably be worse. Maybe the movement could be inferred from the patterns in the clouds, which might indicate in some way the previous wind and from this follows likely wind directions, but generally this would be quite hard.

Having the current wind direction would be very beneficial for predicting future rain movements.

To improve the model, it makes sense to take the temporal aspect into account, by including historical data. So radar scans from 5 minutes ago, 10 minutes ago, etc.

(c) Give two ways to include this additional data into the model. (2 points)

To include this additional data, one would have to implement other models which are able to account for the temporal components.

Two commonly used architectures which allow for learning temporal components are sequential recurrent neural networks, and temporal CNNs. These allow for including the additional data into the model.

13.3 MetNet (4 points)¶

We are not the first people to think about this problem. The paper MetNet: A Neural Weather Model for Precipitation Forecasting has tried to tackle the task of predicting rain from radar images.

(a) Have a look at the MetNet paper and compare their method to your answers in 13.1 and 13.2. What are they doing the same, what are they doing differently? (3 points)

Input enoding: Both MetNet and the recommended approach use radar and satellite data as input, represented in a multi-dimensional tensor, although MetNet additionally includes the target time as input.

Output encoding: MetNet and the recommended approach share similarities in output encoding, as both aim to predict weather conditions at a target time.

Model: MetNet and the recommended approach differ slightly in their model architectures; while both utilize convolutional neural networks (CNNs) for spatial processing, MetNet employs a convolutional LSTM for temporal encoding and axial self-attention blocks for spatial aggregation, whereas the recommended approach suggests using sequential recurrent neural networks or temporal CNNs for temporal modeling alongside CNNs for spatial processing.

(b) Can the trained MetNet be used in the Netherlands using data from KNMI, without retraining? How? Or why not? (1 point)

It probably could not be used. The Netherlands have quite a different climate than the USA, on which the model is trained, so the trained data would be quite different from the required data. This would come to a loss of accuracy. However, the type of data is the same - mm of rainfall per area - , so it could still be run on data from the Netherlands. It is just that the underlying dynamics of the system are probably different enough.

An analogy would be image recognition: If one has trained a model to identify cats, but consequently wants to identify dogs, the task is exactly the same but the data is rather different. We think that similarly here the data is sufficiently different for the model to not return great results.
